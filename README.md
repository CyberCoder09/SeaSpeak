SeeSpeak is an AI powered computer vision application that helps identify objects and colors using camera and
provides a result through text to speech

The project combines YOLO object detection, OpenCV image processing, and Windows Speech Synthesis to create a simple assistive vision tool.

Camera
   ↓
OpenCV captures frame
   ↓
YOLO detects objects
   ↓
User places object inside the guide box
   ↓
Press C
   ↓
Color detection
   ↓
Windows Speech Synthesis
   ↓
"The color is red".
